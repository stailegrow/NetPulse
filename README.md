# NetPulse

Бесплатный мониторинг доступности сети и сервисов для macOS и Windows: непрерывные проверки, трассировка маршрута, отчёты и уведомления.

Автор: **Sorokin Maksim**

- Главный экран со всеми целями сразу: статус, текущая и средняя задержка, jitter, потери и мини-график последних проверок. Цели можно разбить на группы.
- Экран цели построен как классический трассировщик:
  - таблица хопов (узлов маршрута) с полосой задержки;
  - подсветка хопа, с которого начинаются потери;
  - графики задержки и потерь с цветными зонами порогов;
  - на графике можно выделить участок мышью (фокус) и получить статистику только за него.
- Типы проверок: трассировка ICMP (все хопы), Ping, HTTP(S) (код ответа, время, ключевое слово, срок SSL-сертификата), TCP-порт, DNS.
- Метрики: min/avg/max, jitter, потери, MOS (оценка качества VoIP), аптайм за 24 часа и за 7 дней.
- Оповещения настраиваются прямо в программе: системные уведомления, звук, Telegram, Slack/Discord/вебхук, e-mail (SMTP). Есть кнопка «Тест», сообщения о восстановлении и повтор напоминаний.
- Программа отслеживает смену маршрута и смену IP-адреса у имени (DNS).
- История хранится в SQLite: подробные данные и минутные агрегаты, срок хранения настраивается.
- Данные можно выгрузить в CSV, а список целей с настройками — в файл, чтобы импортировать у руководителя или коллег.
- При закрытии окна программа продолжает мониторинг в трее или меню-баре. Цвет иконки показывает, есть ли проблемы. Можно включить автозапуск.
- Права администратора не нужны: на macOS используется непривилегированный ICMP-сокет, на Windows — функции iphlpapi.

## Структура

```
crates/netpulse-icmp   кроссплатформенный ICMP (macOS / Windows / Linux)
crates/netpulse-core   движок: трассировка, проверки, статистика, SQLite, алерты
app/src-tauri          приложение Tauri 2 (окно, трей, уведомления, команды)
app/src                интерфейс React + TypeScript (тёмная тема)
scripts/               сборка для macOS и Windows
ci/                    workflow GitHub Actions (автосборка .dmg и .exe)
```

## Сборка на Mac

```bash
cd ~/Projects/NetPulse
./scripts/build-mac.sh
```

Скрипт всё делает сам:

1. Ставит недостающее: Command Line Tools (появится системное окно, нажмите «Установить»), Node.js и Rust. Права администратора не нужны.
2. Собирает универсальное приложение для Apple Silicon и Intel.
3. Копирует NetPulse в «Программы» и запускает его.

Если нужна только сборка, без установки, запустите `./scripts/build-mac.sh --no-install`.

Для других Mac берите `target/universal-apple-darwin/release/bundle/dmg/NetPulse_1.0.19_universal.dmg`: откройте файл и перетащите NetPulse в «Программы».

**Важно про другие Mac.** Приложение подписано локально, без платного сертификата Apple Developer ID. Если .dmg передан через интернет, мессенджер или AirDrop, при первом запуске macOS спросит подтверждение. Откройте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Это нужно сделать один раз.

Чтобы это окно не появлялось совсем, нужна подпись и нотаризация Apple (Apple Developer Program, $99 в год). Сборка к этому уже готова: достаточно задать переменные `APPLE_SIGNING_IDENTITY`, `APPLE_ID`, `APPLE_PASSWORD` и `APPLE_TEAM_ID`.

## Выпуск обновления для Windows

Установщик Windows собирается отдельно (кросс-компиляцией или на Windows) и кладётся в `dist/windows/`:
`NetPulse_<версия>_x64-setup.exe` и, по желанию, `NetPulse_<версия>_portable.exe`.
Публикация идёт с Mac, где хранится ключ подписи обновлений:

```bash
./scripts/build-mac.sh --windows-only
```

Скрипт подписывает установщик, прикладывает файлы к релизу той же версии и добавляет запись `windows-x86_64` в `updates/latest.json`, не трогая запись для Mac. После этого установленные на Windows копии NetPulse предлагают обновиться сами. Если установщик лежит в `dist/windows` во время обычного `--release`, он публикуется вместе с Mac-версией.

## Сборка для Windows (.exe)

**Вариант 1: GitHub Actions (удобнее всего, собирать можно прямо с Mac)**

1. Переместите `ci/github-actions-build.yml` в `.github/workflows/build.yml`. Затем создайте приватный репозиторий на GitHub и загрузите в него эту папку.
2. Откройте вкладку Actions → **Build NetPulse**. Сборка запускается автоматически при каждом push.
3. В артефакте `NetPulse-Windows` будут:
   - `NetPulse_1.0.19_x64-setup.exe` — установщик;
   - `.msi` — для развёртывания через GPO;
   - `netpulse.exe` — портативная версия.

   Там же, в артефакте `NetPulse-macOS`, лежит `.dmg`.
4. Если создать тег `v1.0.19`, файлы автоматически прикрепятся к релизу.

**Вариант 2: сборка на компьютере с Windows**

Скрипт сам установит Visual Studio Build Tools, Node.js и Rust (через winget) и соберёт установщик:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
```

**Что нужно пользователю Windows:** только запустить `NetPulse_x.y.z_x64-setup.exe`. Права администратора не нужны, Visual C++ Redistributable не требуется (среда выполнения встроена). WebView2 уже есть в Windows 10 и 11; если его нет, установщик скачает его сам. При первом запуске неподписанного файла SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».

## Разработка

```bash
cd app
npm install
npm run tauri dev     # приложение с горячей перезагрузкой интерфейса
npm run dev           # только интерфейс в браузере, на демо-данных (http://localhost:1420)
```

Проверка движка без интерфейса:

```bash
cargo test -p netpulse-icmp -p netpulse-core
cargo run -p netpulse-core --example trace -- 8.8.8.8 3   # трассировка в терминале
cargo run -p netpulse-core --example engine               # сквозной прогон монитора
```

## Где хранятся данные

| ОС | Путь |
|---|---|
| macOS | `~/Library/Application Support/com.netpulse.monitor/netpulse.db` |
| Windows | `%APPDATA%\com.netpulse.monitor\netpulse.db` |

## Горячие клавиши

- `⌘N` / `Ctrl+N` — новая цель
- `⌘,` / `Ctrl+,` — настройки
- `Esc` — назад к списку
